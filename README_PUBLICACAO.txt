PUBLICAÇÃO — RELATÓRIO EXECUTIVO NQI

Arquivos:
- index.html: página principal do relatório
- Modelo_Relatorio_Anual_NQI_Revista.xlsx: modelo para atualização

Hospedagem estática:
1. Netlify: envie esta pasta ou o ZIP descompactado.
2. GitHub Pages: publique o conteúdo desta pasta na raiz do repositório.
3. Vercel: importe um repositório contendo estes arquivos.

IMPORTANTE
Nesta versão estática, o upload do Excel é processado e salvo apenas no navegador
de quem fez a carga. Ele não altera automaticamente o conteúdo visto por outros usuários.

Para uma publicação institucional centralizada, a arquitetura recomendada é:
- site público de leitura;
- área administrativa protegida;
- upload do Excel na área administrativa;
- armazenamento do arquivo/dados em backend;
- atualização automática para todos os visitantes;
- histórico de versões e data da última publicação.
