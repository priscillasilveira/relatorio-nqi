RELATÓRIO NQI — PUBLICAÇÃO CENTRALIZADA

Arquivos principais:
- index.html — site público
- admin.html — instruções/atalhos para publicação
- dados/Relatorio_NQI.xlsx — fonte oficial centralizada

Como atualizar para todos:
1. Preencha uma cópia do modelo Excel.
2. Teste com o botão "Pré-visualizar Excel" no site.
3. No GitHub, substitua dados/Relatorio_NQI.xlsx mantendo o mesmo nome.
4. Faça commit na branch main.
5. O GitHub Pages fará novo deploy e todos verão a mesma edição.

Observação:
O botão de upload no site público é apenas para pré-visualização local.
