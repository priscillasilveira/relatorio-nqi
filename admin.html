Valide localmente

No relatório público, use “Pré-visualizar Excel” para conferir a nova base antes da publicação.

2

Abra a pasta de dados no GitHub

A publicação usa o login do GitHub como proteção administrativa. Apenas pessoas com permissão de escrita no repositório conseguem substituir o arquivo oficial.

3

Substitua o arquivo

Apague ou sobrescreva dados/Relatorio_NQI.xlsx usando exatamente o mesmo nome. Não altere a estrutura das abas/colunas do modelo.

4

Confirme o commit

Use uma mensagem como “Atualiza relatório NQI — 2026-10-06”. O GitHub Pages fará o deploy automaticamente.
